# MindMorphia

Site oficial da **MindMorphia**, uma marca do Grupo SV.

## Produção

- `index.html` — página pública oficial
- Site estático, responsivo e preparado para publicação na Vercel
- Formulário de contato integrado ao e-mail institucional
- Identidade visual, animações e metadados de SEO incluídos no próprio projeto

## Atualizações

Alterações de produção devem ser feitas no `index.html`. Quando o repositório estiver conectado à Vercel, novos commits na branch `main` poderão gerar novas publicações automaticamente.
