# MindMorphia

Site oficial da **MindMorphia**, uma marca do Grupo SV, e ponto central de registro dos projetos web que ainda não possuem repositório GitHub próprio.

## Produção MindMorphia

- `index.html` — página pública oficial da MindMorphia
- Site estático, responsivo e preparado para publicação
- Identidade visual, animações e metadados de SEO incluídos no próprio projeto

## Central de sites

Para evitar versões dispersas, o inventário canônico está em:

- **`WEBSITES.md`** — registro central de todos os sites/páginas identificados
- **`sites/`** — projetos sem repositório próprio
- **`projects/`** — homologações e projetos em desenvolvimento

Projetos com repositório próprio permanecem separados dentro da organização GitHub **MINDMORPHIA** para não duplicar código.
