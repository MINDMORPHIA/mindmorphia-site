# Central de sites — MINDMORPHIA / Grupo SV

Este diretório funciona como índice central dos projetos web que não possuem repositório próprio.

## Regra operacional

- Todo site/página ativa deve ter fonte ou snapshot de referência no GitHub.
- Projetos com repositório próprio continuam separados para evitar mistura de código.
- O arquivo `/WEBSITES.md` é a fonte única de localização dos projetos.
- Projetos ainda não publicados ficam registrados como **em desenvolvimento**, sem serem confundidos com produção.
- A publicação (Vercel, domínio próprio, ChatGPT Site, Higgsfield etc.) é ambiente de entrega; o GitHub é a referência de código e histórico.
