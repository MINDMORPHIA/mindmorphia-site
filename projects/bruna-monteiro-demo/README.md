# Bruna Monteiro — demonstrativo para influenciadoras

**Status:** demonstrativo / conceito em desenvolvimento.

Bruna Monteiro é a persona fictícia usada como referência de categoria para páginas de influenciadoras de moda, provador e lifestyle. Não é um cliente real e não deve ser tratada como template obrigatório.

## Regra

- O demonstrativo deve parecer uma página oficial da persona.
- Não incluir textos internos de bastidor.
- Preservar o nível de qualidade, não copiar automaticamente a estética em novos clientes.
- Quando houver uma versão de código consolidada, ela deve ser registrada neste diretório/repositório antes de ser apresentada como versão canônica.

Centralizado como projeto no GitHub em 05/10/2026.
